# Julio Vivas Portfolio

Source code for the personal portfolio published at `https://dino-julius.github.io/`.

## Repository Map

- `julio-vivas-portfolio`
  - Main source repository.
  - Edit React components, portfolio content, styles, and deployment config here.
  - Pushes to `main` trigger the deploy workflow.

- `Dino-Julius.github.io`
  - Published GitHub Pages repository.
  - Receives generated files from this repo's `dist` folder.
  - Do not edit this repo by hand for portfolio changes, because the next deploy will overwrite generated assets.
